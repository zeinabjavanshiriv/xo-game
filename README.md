The simple XO game built with python (Tic-Tac-Toe)



About:

This is begginer-friendly console version of classic Tic-Tac_Toe game.
Computer and player placing to X or O 
First who get 3 in one row will win.




Features:

Play with computer 
Winner check
Detecs a draw 
prevents invalid move
Allows to play again 



Built with:

Python 3
Lists
Funcs
Loops
Condition
Random library
